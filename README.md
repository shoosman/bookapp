# Чтец

Android-приложение: читалка и аудиокниги в одном месте, с переключением между текстом и звуком.

- Библиотека с полками «Читаю», «Хочу прочитать», «Прочитано», «Брошено», оценки
- Читалка: FB2, FB2.ZIP, EPUB, TXT, DOCX, HTML; темы, шрифты, оглавление, закладки
- Плеер: MP3, M4B/M4A, OGG/Opus, FLAC; скорость 0.5–3×, таймер сна, фоновое воспроизведение
- Синхронизация текста и аудио: по главам и длительности + ручные точки привязки

Сборка: GitHub Actions (`.github/workflows/build.yml`) собирает подписанный APK при каждом push в `main`.
